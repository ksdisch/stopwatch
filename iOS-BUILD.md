# Tempo — iOS Build Reference

Operational notes for the Capacitor iOS wrapper around Tempo. The web build (`https://ksdisch.github.io/stopwatch/`) deploys via `git push` to GitHub Pages and is unaffected by anything in this doc — these instructions only apply when working with the native iPhone build.

For architectural details and where the abstraction layer lives, see `CLAUDE.md` → "iOS build (Capacitor)". This file is the day-to-day playbook.

## Repo layout

```
js/platform.js                  ← haptics + notifications abstraction
capacitor.config.json           ← appId / appName / webDir
package.json + node_modules/    ← Capacitor + plugins (node_modules gitignored)
scripts/sync-www.mjs            ← mirrors repo root → www/
www/                            ← gitignored, regenerated by sync-www
ios/                            ← committed Xcode project
ios/App/Pods/, ios/App/build/   ← gitignored (reproducible)
```

## Updating the app on your iPhone

When you change any web code (`js/`, `css/`, `index.html`, etc.) and want it on the phone:

```bash
cd /Users/kyledisch/Projects/stopwatch/.claude/worktrees/charming-spence-31e861
npm run ios:copy
```

That runs `sync-www` to regenerate `www/` from the repo root, then `cap copy ios` to push it into the iOS bundle.

Then in Xcode hit `⌘R` (Run). If Xcode is closed, run `npm run ios:open` instead — it does the copy AND opens Xcode in one step.

The web version updates separately and instantly via `git push` to GitHub Pages.

## The 7-day signing cert (free Apple ID limitation)

Free Apple ID signing issues a **7-day** development cert. After 7 days, the Tempo app on your iPhone won't launch — tapping the icon just bounces you back to the home screen.

To refresh:

```bash
cd /Users/kyledisch/Projects/stopwatch/.claude/worktrees/charming-spence-31e861
npm run ios:open
```

In Xcode, plug in your iPhone, select it as the destination (top-center dropdown), hit ▶ Run. Takes ~30 sec. The cert resets to a fresh 7 days.

You can do this any time before the cert expires — there's no penalty for re-deploying early.

If you want to escape this maintenance, the $99/yr **Apple Developer Program** gives you:
- 1-year certs (renew once a year instead of weekly)
- TestFlight (share with up to 10,000 beta testers without App Store review)
- App Store distribution (anyone with an iPhone can install)

For solo use it's overkill. If you ever want to share Tempo with others or stop refreshing weekly, that's the upgrade.

## Web behavior is unchanged

The Capacitor wrapper is purely additive. The web build is byte-equivalent to before:

- All 23 haptic call sites and 6 immediate-notification sites now go through `Platform.haptic` / `Platform.notify`, which on web delegate to `navigator.vibrate` / `new Notification` exactly as before.
- `BgNotify.schedule` / `cancel` still post to the service worker on web; only on native do they bypass the SW and go straight to `LocalNotifications`.
- The service worker still registers on web (`js/app.js` gates registration on `!Platform.isNative`). Push to `main` → GitHub Pages deploys → cached SW updates after the next visit.
- Engine tests (`tests/index.html`, 265 cases) run unchanged on web.

If you ever notice web behavior drift (e.g., haptics stop working on Android Chrome), check `Platform.haptic` in `js/platform.js` — the web path is just `navigator.vibrate(pattern)` and should be a one-line passthrough.

## Daily workflow cheat sheet

| Task | Command |
|------|---------|
| Update web build | `git push` (deploys in ~1 min) |
| Sync iPhone build (Xcode already open) | `npm run ios:copy` then `⌘R` in Xcode |
| Sync iPhone build (Xcode closed) | `npm run ios:open` |
| Refresh 7-day cert | `npm run ios:open` → ▶ Run |
| Run engine tests | open `tests/index.html` in any browser |
| Bump SW cache (after asset changes) | edit `CACHE_NAME` in `sw.js` |

## Out of scope for the current build

- $99/yr Apple Developer Program enrollment (free signing is fine for personal use)
- App Store Connect record
- TestFlight or App Store submission
- Privacy nutrition labels (meds + BFRB tracking are health data and would need disclosure for App Store distribution)
- App Review screenshots
- Age rating
- App icon polish (Apple wants 1024×1024 PNG for App Store; current 192/512 PNGs work fine for personal install)
- `BGTaskScheduler` for true long-running native background work — not needed because `LocalNotifications` schedules at the OS level, and engines are drift-free (`elapsed = offsetMs + accumulatedMs + (Date.now() - startedAt)` recomputes correctly on resume)
- Audio session control (silent switch / ducking music when chimes play) — Web Audio still gets cut by music on native; revisit only if it becomes annoying
- Capacitor Preferences vs `localStorage` — `localStorage` works in `WKWebView` and the data is preserved across launches, no migration needed
