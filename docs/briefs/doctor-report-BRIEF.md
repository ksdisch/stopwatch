## What this PR ships

**1. New engine `js/doctor-report.js`** (IIFE singleton `DoctorReport`, zero DOM):

- `buildReport({ days = 30, now = Date.now() } = {})` → `Promise<string>`: a
  paste-friendly plain-text summary with sections:
  - **Header**: window ("Last 30 days" + explicit date range), generated-on date.
  - **Medications** (from `MedsManager.all()` + `Analytics.getMedAdherence(days)`):
    per med — name, dose, frequency, doses logged in-window, last taken; scheduled
    meds also show adherence %; as-needed meds show counts only.
  - **Sleep** (from `wellness_rest_log`): days logged as coverage ("N of M days"),
    avg hours, avg quality (when present), bedtime/wake range when logged, nap count
    + total nap time.
  - **Activity & focus** (from `History.getSessions()` in-window): total focus time
    (flow + pomodoro), session count, mindful session count (tag `mindful`),
    exercise/interval session count. Cooking excluded.
  - **Footer**: "Generated by Tempo. Data as logged by the user — descriptive only,
    no medical interpretation."
- Descriptive-first copy; **empty-state is the DEFAULT path** — any missing/empty store
  renders a "No X logged in this window." line; malformed rows are skipped, never
  thrown on.
- Strictly read-only: NO writes to any store, no `js/schema.js`, no sync modules.
- Expose pure helpers via `_internals` (window filtering, per-section builders) so
  tests can clock-pin without IDB where possible.

**2. Additive generic text helpers in `js/export.js`** (mirror existing patterns; no
changes to existing functions or export/import data shapes):

- `copyText(text)` → clipboard (mirror the module's existing clipboard path).
- `shareText(title, text)` → `navigator.share` when `canShare()`, else `copyText`
  fallback (mirror `share()`).
- `downloadText(filename, text)` → mirror `downloadCSV()`'s blob path.

**3. UI trigger + view surface** (ui-wirer phase):

- ONE trigger reachable from the Wellness area or the History/export surface — the
  auditor recommends the exact placement (smallest coherent blast; the History panel's
  export row and the Wellness hub are the candidate anchors).
- Tapping it builds the report and shows it in a scrollable panel/modal matching an
  existing panel pattern, with **Copy / Share / Download** actions wired to the new
  Export helpers; `Toast` confirmation on copy.
- Panel dismissible; action buttons ≥44px per the mobile-sweep norms.

**4. Wire-points (DoD #3)** — new module ⇒ all four: `index.html` `<script>` slot (load
after `analytics.js` + `export.js`, before its UI consumer), CLAUDE.md file-map +
load-order chain, `sw.js` ASSETS + `CACHE_NAME` bump, `tests/doctor-report.test.js`
registered in `tests/index.html`.

## Hard rules

  self-reviews the audit — no user pause, but every audit risk must be addressed or
  explicitly accepted in the final report.
- **No synced-store writes; no sync-engine/merge-module edits; no native code; no new
  persisted keys** (⇒ no data-dictionary change).

  rendering), `Analytics.getMedAdherence`, existing Export seams. Do NOT re-implement
  adherence math or time formatting.
- Engine tests clock-pinned (fixed `now`); cover: window filtering, meds section
  (scheduled + as-needed), sleep averages, focus aggregation, the all-empty report,
  malformed-row resilience.

- Arc constraints (hygiene 2026-07-19): no iPhone-in-hand steps anywhere in the
  verification plan.
