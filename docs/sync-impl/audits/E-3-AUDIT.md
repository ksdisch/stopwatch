## Goal

Replace the 30s `setInterval` polling cycle with real-time `onSnapshot` listeners so cross-device cloud-to-local propagation drops from ~30s (best case, ideal conditions) / unbounded (iOS Safari WebView suspended) to <1s + debounce window. Layer the listeners ON TOP of a demoted 5-minute defensive poll so silent listener failure has a bounded recovery time. Introduce the first user-facing F19a surface — a downlevel-client warning toast that fires once per session when this device sees a future-schema record, prompting the user to update Tempo on their other device. Close E-2's `js/sync-engine.js:1842` symmetry follow-up as a one-line ride-along since E-3 already modifies the same lifecycle neighborhood.
